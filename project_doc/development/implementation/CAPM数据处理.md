# CAPM数据处理

## 1. 文档用途与当前状态

本手册由用户要求独立建立，随 P5B 实现同步维护。需求范围、确认记录与待决项以 [P5B 计划](../plan/P5B_PLAN.md) 为入口；本手册集中说明数据从哪里来、如何变成指标、结果如何保存，以及实际实现和验证状态。

**当前已有 CAPM 本地分析、结果保存及共用 P5 流水线的独立参考数据同步。最新实现与验证以 9.5 节为准；前文保留的草案及 9.1–9.4 首批实现描述是历史记录，不作为当前接口/完成状态。** 未实现的扩展和 Baostock 不提供的能力不据此视为完成。

2026-09-03 核对现有代码：`code/src/stock_manager/protocols.py::ProviderProtocol` 尚无独立指数目录、历史成分/权重或存款利率端口；`code/src/stock_manager/providers/baostock_provider.py::fetch_stocks` 保持 A 股股票池边界，指数不会作为股票加入筛选。P4 提供股票本地只读基础设施，具体架构约束见 [P4 ADR](../architecture/ADR_P4_READ_LAYER.md)。

## 2. 已确认的计算口径

| 项目 | 当前约定 |
|---|---|
| 分析对象 | 用户点击的单只通过股票；未点击不自动计算 |
| 市场基准 | 默认沪深300价格指数 `hs300.price`；来源实际提供的其他收益版本独立保存 |
| 配置归属 | 全部模板共用项目设置，分析使用提交时冻结的配置 |
| 股票输入 | 同一版前复权 `qfq` 价格 |
| 收益频率/公式 | 日频、简单收益率：$P_t / P_{\mathrm{prev}} - 1$；个股与基准一致 |
| 窗口与日期 | 自然日窗口，截至日固定筛选日期，保留最近 30 个自然日窗口；其他窗口集合待定 |
| 股票准入 | 至少半年有效历史；满足后可以计算短于半年的窗口；半年有效性的精确判定仍待冻结 |
| 无风险代理 | 默认央行人民币整存整取一年期存款基准利率，各窗口统一，期限可调整 |
| 利率区间换算 | 实际自然日、固定 365 分母、单利：$r_f = r \times d / 365$（$r$ 为年利率、$d$ 为区间自然日数，口径同第 4 节） |
| alpha 展示 | 日频原始值与线性年化值同时显示，允许指标排序 |
| alpha 年化 | $\alpha_{\mathrm{annualized}} = \alpha_{\mathrm{daily}} \times \mathrm{periods\_per\_year}$；默认 $\mathrm{periods\_per\_year} = 252$，项目设置可调整 |
| beta | 无量纲，不作年化 |
| 保存 | SQLite 规范化保存结果及模板、股票、日期、窗口、配置和来源信息 |

**252 与 365 分别配置。** 252 是本项目选择的每年收益观察次数约定，不是对任意 A 股年份实际交易日数量的断言；365 是无风险代理按自然日计息的分母。修改一个不能自动修改另一个。年化不是未来收益预测，原始 alpha 也不是窗口累计超额收益。

## 3. 指数及其资料

| 宽基 | 沪深300为默认 CAPM 基准；其他宽基供研究复用 | 目录清单、收益版本、行情/成分/权重覆盖待逐项验收 |

### 3.2 各类资料的意义

| 数据 | 用途 | 必须区分的元数据 |
|---|---|---|
| 指数目录 | 确定对象身份、分类与来源能力 | 名称、稳定身份、Provider 代码、编制机构、分类体系、收益版本、币种 |
| 指数行情 | 计算基准日收益 | 交易日、点位、来源、获取时间、收益版本、数据版本/摘要 |
| 历史成分 | 记录某时点成员，供以后研究 | 成员代码、快照身份、生效时间、公告/可用时间、获取时间、覆盖状态 |
| 历史权重 | 记录真实公开快照中的权重 | 成员代码、权重及单位、权重基准时点、快照频率、来源、修订证据 |

首期 CAPM 使用已发布指数序列计算市场收益，不要求用历史成员和权重重新编制沪深300；成分及权重仍需按用户要求保存。不能用当前成员回填历史，也不能以等权、插值或每日复制替代缺失的官方权重快照。只有日期而无公告时点的资料，不声称满足精确的历史可得性要求。

### 3.3 来源能力与当前缺口

行情仍沿 Baostock Provider，不能擅自替换数据源。已有 SDK 静态核验确认 `query_hs300_stocks`、`query_sz50_stocks`、`query_zz500_stocks` 存在；这不证明指定日期可返回完整八年历史成分，也不证明历史权重可获取。全部类别、历史权重与利率实际远端覆盖尚未实测。

实现时在本节维护逐项证据表：指数身份、收益版本、数据类型、实际接口、最早/最新日期、快照频率、使用限制、缺口、核验时间及状态。部分覆盖必须明确报告，不能用空表、字段预留或未来支持计划充当数据交付。

## 4. 利率来源、时间与单位

无风险代理的原始发布机构为中国人民银行，优先核验现有 Baostock 渠道的 `query_deposit_rate_data()`。渠道与发布机构分别记录；不替换为中国银行挂牌利率、贷款基准或 LPR。项目当前适配器尚未封装该接口，官方文档样例不能代替实际可用性测试。

建议保存币种、品种、期限、原始利率与单位、归一化年利率、发布日期、生效日期、获取时间和来源引用。源值 `1.50%` 在计算中为 `0.015`；不把百分数数值 `1.50` 直接参与收益计算。`pubDate` 不能未经核验直接当作生效日。

对于区间内不变的年利率 $r$，两个收益端点间实际跨越 $d$ 个自然日：

$$r_f = \frac{r \times d}{365}$$

这是已确认的 ACT/365F 单利约定。周末、节假日和闰日计入 $d$；闰年及跨年时分母仍为 365。不进行利息滚存，不使用 $(1 + r)^{d/365} - 1$ 替代。

**例子：**仅为演算，假设年利率为 1.50%，周五收盘至周一收盘跨 3 个自然日，$r_f = 0.015 \times 3 / 365 = 0.000123287671\ldots$，即约 `0.01232877%`。股票和指数各产生对应的一条交易区间收益，不补造周末股票收益。

历史区间使用当时有效利率还是固定当前利率，尚待确认。Agent 建议按当时有效记录取值，跨调息日按生效日期分段后分别计算单利并求和；具体端点归属与公告时点未知时的规则尚未冻结，不能默认为已采纳。初次同步应取得目标起点前适用记录；“区间无新调整记录”不等于利率为零。

## 5. 从本地价格构造简单日收益

所有日期基于 `Asia/Shanghai` 和 A 股交易日历。筛选日期固定为分析截至日；股票半年资格也在该日期判断，不用今天的数据长度替代历史资格。30 天指自然日窗口内的真实交易日观察，其精确端点归属与有效样本门槛仍待冻结。

股价必须来自同一版 `qfq`；指数记录自身收益版本，不伪造股票复权标签。同步层沿用既有除权修复约束，CAPM 不新增第二套修订或联网逻辑。新旧复权尺度不得拼接；旧结果的必要版本信息保留，但首期不承诺完整原始输入历史重放。

对两个相邻有效观察端点，简单收益率为：

$$R_{\mathrm{stock},t} = \frac{P_{\mathrm{stock},t}}{P_{\mathrm{stock},\mathrm{prev}}} - 1, \qquad R_{\mathrm{market},t} = \frac{I_t}{I_{\mathrm{prev}}} - 1$$

例如股票同版 qfq 价格由 10 变为 10.50，收益率为 `0.05`，展示为 `5%`；基准点位从 100 变为 102，收益率为 `0.02`。不采用对数收益。价格/点位必须有效、有限且可作为合法分母；非法数据不能产生正常结果。

第一条收益需要前置价格，因此 N 个收盘观察通常只形成 N−1 条相邻收益，不能把价格数当成收益数。停牌或缺口后是否跨多日计算、删除区间或拒绝窗口仍须冻结；不得静默把多交易日跨度当作普通单交易日观察。

个股、指数与无风险代理必须使用相同的起止端点对齐。不能按行号拼接，也不能把股票周一至周三收益与指数周二至周三收益配对。窗口天数、股票历史资格、有效收益条数分别记录。

价格指数与全收益指数的现金分红处理不同；同一简单收益公式不意味着输入版本已兼容。实现前须核验所选沪深300版本及 Baostock qfq 的实际口径，防止分红遗漏或重复加入。

## 6. CAPM 回归与 alpha 线性年化

对已对齐的区间收益，构造：

$$x_t = R_{\mathrm{market},t} - R_{f,t}, \qquad y_t = R_{\mathrm{stock},t} - R_{f,t}$$

$$y_t = \alpha_{\mathrm{daily}} + \beta\, x_t + \varepsilon_t$$

纯数学核心消费结构化超额收益，不访问网络或数据库。拟采用含截距的一元普通最小二乘回归，中心化公式如下；具体函数签名、数值容差及样本门槛随实现契约冻结：

$$\begin{aligned}
\beta &= \frac{\sum_t (x_t - \bar{x})(y_t - \bar{y})}{\sum_t (x_t - \bar{x})^2} \\[2pt]
\alpha_{\mathrm{daily}} &= \bar{y} - \beta\, \bar{x} \\[2pt]
\varepsilon_t &= y_t - \alpha_{\mathrm{daily}} - \beta\, x_t \\[2pt]
R^2 &= 1 - \frac{\sum_t \varepsilon_t^2}{\sum_t (y_t - \bar{y})^2}
\end{aligned}$$

市场超额收益零方差时无法唯一估计此回归，不返回伪造的正常 alpha/beta。资产超额收益常量时 R² 的分母为零，即使部分系数可估计，也不能静默把 R² 填成 0 或 1。缺失、非有限数值与不足样本应产生明确状态，具体对外原因码尚未实现。

**用户已确认线性年化及可调整默认因子：**

$$\alpha_{\mathrm{annualized}} = \alpha_{\mathrm{daily}} \times \mathrm{periods\_per\_year}$$

当前项目默认 $\mathrm{periods\_per\_year} = 252$，允许调整。

不是 $(1 + \alpha_{\mathrm{daily}})^{252} - 1$，也不是 $\alpha_{\mathrm{daily}} \times 365$。以小数存储的日频 alpha `0.0002` 对应 `0.02%`；默认年化结果为 `0.0504`，展示 `5.04%`。beta 保持无量纲，不生成“年化 beta”。

30 天窗口、半年窗口估计出的 alpha 均对应日收益频率；年化乘数取项目配置，不把 30、半年天数或该窗口有效样本数直接作为年化因子。调整因子后新分析使用新配置；旧结果保存当时因子及方法，不能因当前设置变化被重新解释。

### 数学核对样例

以下为人工可算的超额收益 fixture，不代表真实股票，也不满足或替代产品的半年准入门槛：

| 观察 | 市场超额收益 x | 股票超额收益 y |
|---|---:|---:|
| 1 | -0.02 | -0.0298 |
| 2 | -0.01 | -0.0148 |
| 3 | 0 | 0.0002 |
| 4 | 0.01 | 0.0152 |
| 5 | 0.02 | 0.0302 |

满足 $y = 0.0002 + 1.5\, x$，预期 $\alpha_{\mathrm{daily}} = 0.0002$、$\beta = 1.5$、$R^2 = 1$；默认年化 alpha 为 `0.0504`。实现时应加入含非零残差的样例与数值容差验证；本手册演算不声称生产回归实现或其测试已通过。

## 7. 同步、计算、展示与保存边界

1. **同步：** 外部访问仅由 `DataSyncService` 编排 Provider，串行、受控限速并设置超时。按本地覆盖补尾部、内部缺口与新增对象；成功分区跳过且提示，不每次重拉八年。
2. **发布：** 沿现有 staging、完整性核验和原子发布机制。指数日线、成分快照、权重快照与利率调整事件分别定义完整性，不能套用股票池 95% 门槛。失败不得标成成功，无新利率调整不冒充失败或零利率。
3. **点击：** 先显示筛选名单，再分析用户点击的股票；只读本地已发布数据。缺 CAPM 专用指数或利率数据不能阻止原筛选名单展示。
4. **计算：** 冻结配置及输入身份，校验半年资格、窗口与口径，构造同区间简单超额收益后计算。各窗口使用同一版输入，不混合发布前后数据。
5. **展示：** 原始/年化 alpha、beta、窗口和状态可辨识。排序建议按所选窗口与指标进行，未计算/不可估计行单独处理，不为排序自动计算未点击股票；具体交互仍待冻结。
6. **保存：** 写入经过 Storage，并以事务保存结果、来源和状态；只有提交成功才显示已保存。历史查询/统计/导出界面延期，不取消首期结果保存。

建议记录粒度为“筛选来源 × 股票 × 截至日 × 窗口 × 分析配置/输入版本”。拟议字段如下，实际 DDL 尚未建立：

| 字段组 | 需要保留的内容 |
|---|---|
| 来源身份 | 筛选运行、模板 ID/revision、名称快照、实际模板摘要 |
| 股票与时间 | 股票代码、筛选截至日、计算时间、窗口单位/大小、实际端点、有效观察数 |
| 指标 | 原始 alpha、线性年化 alpha、beta、R²及其有效状态；不可估计为 NULL 和原因 |
| 配置 | 沪深300精确身份/收益版本、`qfq`、简单收益、利率品种/期限、ACT/365F、单利、线性年化、实际年化因子、配置版本 |
| 证据 | 数据来源、获取时间、输入版本/摘要、模型版本、实际覆盖和缺口 |

相同请求去重，不用模板名/日期作为唯一身份，不把不同股票或窗口相互覆盖。新设置产生新分析身份，在途任务继续使用提交时的配置；历史结果不随模板改名、利率期限或年化因子变更而改写。

现有 [DataSync 数据库 ADR](../architecture/ADR_P5_DATASYNC_DATABASE.md) 仅保证 active generation 的读取，旧 manifest 不保证旧行情行可重放。保存版本号/摘要不等于保存全部输入；首期不新增完整历史复现模块。

## 8. 异常与尚待确定的边界

共同底线：不填零伪装缺失，不自动换基准/利率/复权，不静默缩窗，不在点击计算时联网，不吞掉底层读取或保存异常。

| 情况 | 当前确定内容 | 尚需冻结 |
|---|---|---|
| 新股/历史不足 | 半年有效历史是准入门槛，不足不计算 CAPM | 六个日历月或固定天数；完整性与有效观察门槛 |
| 某窗口不足 | 不伪造收益或完整窗口 | 是否保留其他有效窗口；各窗口最低观察数 |
| 停牌/缺口 | 不把无交易直接当普通零收益或静默跨缺口 | 按区间排除、拒绝窗口或其他明确规则 |
| 指数/利率缺失 | 不换源、不换品种、不填 0；原筛选仍可显示 | 逐输入/逐窗口失败范围与原因码 |
| 非法、重复、无序数据 | 不产生未经核验的正常结果 | 标准化与拒绝职责、稳定错误分类 |
| 输入发布/配置更新 | 同次分析不混版，旧响应不覆盖其他股票的新视图 | 在途任务取消、重启恢复、同步后刷新策略 |

此外待定：沪深300价格/全收益版本及分红兼容性；具体行业/风格目录；历史利率映射、端点和跨调息切分；其他窗口集合；真实供应覆盖及资源/性能预算。简单收益率、线性年化、252 可调整默认与365单利已确认，不再列为待选方法。

### 9.1 2026-09-03 首批实现证据

## 10. 依据与说明

- [P5B 计划](../plan/P5B_PLAN.md)：本项目已确认需求、范围及待决项。

- [央行历史存款基准表](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/125440/125838/125888/2887261/index.html)：期限与历史利率单位依据，不把旧表数值称为当前报价。

- [NBIM 风险调整收益方法第 2.1.3 节](https://www.nbim.no/contentassets/fdd69abfff8445cc967c30322b2d3968/factor-and-risk-adjusted-return_2024.pdf)：超额收益回归截距与线性年化方法；项目日频 252 为用户单独确认的可调整参数。
