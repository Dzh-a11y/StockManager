## 已登记快照 as_of 选择（1.17.2）

筛选的 `as_of`（单日快照日）候选**只来自本地已登记的快照交易日**（`dataset_metadata` 中 dataset_id=`market`、adjustment=`qfq` 的行），不掺入只有行情日线但未登记发布的日期。具体表现：

- 数据页（「数据初始化与同步」）就绪后，「本地已登记快照 · 进入前请选择」列出最多最近 10 个已登记快照交易日（倒序，每行含交易日、source、登记时间与 generation，最新项默认勾选并标注“最新”），勾选后进入筛选工作台。
- 工作台「运行筛选」的**交易日**由任意日期输入改为下拉，候选与上述列表一致（只列已登记快照，默认选中门禁所选/最新）；未登记的日期无法手输，也不会被引擎接受。
- 只有已登记快照日可作 as_of；09-02/09-03 等有日线但未登记的历史交易日不提供为 as_of 候选（回测历史资格筛选等按交易日历逐日计算的能力不受影响）。

## 紧凑工作台与个股研究（1.15.2）

主工作台八个模块均可点标题栏的「收起 / 展开」。折叠不清除临时编辑、筛选结果或图表，状态保存在本浏览器。筛选模版、策略模版、运行参数和结果可分别收起，减少滚动；浏览器禁用存储时仍可使用，但会提示无法记忆。

点击筛选结果中的股票后，页面展开并定位到独立的「个股研究」区，位置在「数据同步与维护」上方。桌面依次显示符合条件、日 K 与成交量、CAPM；窄屏按相同顺序纵向排列。通过与未通过条件明确区分，未参与规则默认折叠。K 线仍支持缩放、平移和鼠标查看价格/成交量。

通过筛选的选中股票自动用本地数据计算 CAPM；未通过的股票仍可看条件和行情，但不启动 CAPM。下方可切换已发布市场指数、实际可用利率期限和正整数年化因子，切换会重新计算，不会触发行情同步。默认沪深300价格指数、一年期、252；设置由本浏览器全部模板共用，不修改模板或已保存分析的参数。

指数选项显示真实名称、来源代码及价格/全收益版本；当前本地没有某个版本就不列为可用项。当前 Baostock 同步只保存一年期存款基准利率，因此利率只有真实入库的一年期可用。利率栏显示筛选截至日的有效年率、生效日和来源；历史计算仍逐区间使用当时有效利率，并非用今天的利率替换整段历史。

CAPM 表格展示 30/120/250/500 自然日窗口、有效样本数、状态、日 α、年化 α、β 和 R²。下方公式说明可折叠；「假设与局限」解释低/负 α 只对应历史样本中的模型调整后表现，不等于未来没有机会，也不能据此判定显著性。完整数学口径见 [CAPM数据处理](../development/implementation/CAPM数据处理.md)。

参数、选股、筛选日期和参考数据版本变化后不复用错误上下文的结果；CAPM 重算不会重置 K 线缩放。股票池版本变化时，旧筛选详情停止复用并提示重新筛选，避免旧条件与新行情混用。数据缺失或计算失败显示原因，可通过对应按钮显式重试；不会自动换指数、换利率或补造价格。

## CAPM 数据同步与缺口提示（1.15.1）

数据页有两个独立入口：「股票筛选池回补和同步」及「CAPM 回补和同步」。两者共用同步设施，但各自发布数据 generation；只同步 CAPM 不会更改股票池版本。数据仍只来自 Baostock。

CAPM 同步按来源实际返回验收：请求成功且返回行情合法时，允许保存有历史缺口的指数。页面会以琥珀色显示「同步验收通过并已发布 · 历史不完整」，并列出指数名、来源代码、实际/应有记录数、覆盖率；展开指数条目可看全部缺失日期和范围。缺口表示本次来源未返回，不代表永久不可获取；系统不会补造价格。

看到旧版「完整性校验未通过」时，更新服务并刷新页面后，点击原 CAPM 按钮显式重试。系统先复核已下载的暂存批次，符合新验收即可发布，无需重下八年；网络错误、非法行情、缺有效一年期利率或默认沪深300完全无价格仍会失败。通过新规则发布的数据再次同步时会提示已有数据并跳过，已披露的历史缺口不会触发循环下载。

「同步已发布」不等于所有日期均可计算 CAPM。分析仍验证所选指数及分析范围，遇缺失明确提示 `DATA_INCOMPLETE`；完整基准不受其他指数历史缺口影响。股票池的 95% 门槛、CAPM 的 180 自然日准入及每窗口至少 15 条有效收益要求不变。

## 页面加载与首屏（非阻塞启动）

打开或刷新页面后**直接进入「数据初始化与同步」页**（本地库选择、数据状态与回补入口），不再有等待“检查本地数据”的加载关卡。规则、模板与本地数据状态在后台并行拉取：顶栏服务徽标由“连接中…”转为“服务正常”或“部分加载失败”；数据页标题先显示“数据状态：正在检查本地数据…”，结果返回后自动渲染为最近同步日、覆盖与色块。状态或资源拉取失败只提示、不清空界面，不影响其它功能。

数据就绪时，数据页显示**已登记快照交易日**候选（`dataset_metadata` 中已登记、最多最近 10 个、默认勾选最新）与「使用所选数据库进入筛选工作台」按钮；数据未就绪（首次运行或回补中）时，该页显示“数据部分就绪 / 首次启动”引导与「开始初始化」入口，就绪后仍需用户显式点选进入筛选工作台，**不再按就绪度自动跳转**。首次运行（本地无数据）时后台数据库检查本身是毫秒级，打开页面即可看到初始化引导。

## 功能概览

- **本地优先**：行情数据由同步服务从 Baostock 拉取后写入本地 SQLite（`data/market.sqlite3`）；筛选、Web 与 CLI 查询只读本地数据库，断网可运行。
- **参数化筛选**：内置 12 条可配置规则，模板可开关规则、调整参数与组合；运行条件可配置筛选并发数（Worker 数 1~16，默认 4）——worker 越多筛选越快，但内存与 CPU 占用越高，小数据量时收益不明显；筛选完成后在结果区显示本次用时。
- **本地 Web 工作台**：加载/编辑模板、开关规则、修改参数、调整组合、运行筛选并查看逐股结果与进度；点击筛选出的个股自动展示本地日K线与成交量，K 线信息栏同时展示「涨幅次数」规则命中的涨幅日期，K 线支持滚轮/按钮缩放与左右平移。
- **数据状态可视化**：顶部显示包版本号；“数据状态”卡片按自然日渲染近 30 天逐日同步状态色块（已同步=绿、同步中/未完全同步=琥珀、失败=红、缺失=灰、非交易日=浅），并用 11 段约 30 天窗口展示近 360 天覆盖率；覆盖不足（未完全同步）的天以琥珀色提示。
- **自动补齐**：进入新的已完成交易日后首次启动自动同步补齐历史数据；同一交易日同步成功后不会重复拉取，标记为失败或不完整的交易日会在后续回补时重新拉取刷新。
- **双平台一键启动**：macOS 与 Windows 均支持双击启动，首次运行自动创建虚拟环境并安装依赖。
- **独立回测系统视图（P5C，1.16.0）**：工作台顶栏「回测系统 →」进入独立整页视图（左=回测基础数据、中=策略模版、右=回测结果/历史）。入场与退出各支持 1~5 条政策并列（同名不同参，组内 OR/AND），独立多档止盈（全额退出优先），命名策略模板可保存/另存/删除；运行级基础数据含近 1/3/5/8 年或自定义日期窗口、费用组与整手、单股/忽略资格模式；成交行可点击复盘买卖点在日 K 上的时间戳标注。回测由 Backtrader 引擎驱动，采用 A 股执行模型（T+1 卖出约束、次日开盘成交、整手、停牌/涨跌停限制）。
- **策略机制**：内置回调入场（筛选通过后等价格自近 N 日高点回落再买入）、止盈减仓（涨幅达到阈值后卖出部分持仓）、补仓（买入后成本回撤且有现金则加仓）、均线策略（低于 N 日均线买入、高于 N 日均线卖出）等机制，可与资格、排名、执行政策自由组合。
- **八年历史回补**：首次启动自动以「最新已完成交易日」为终点向前回补八年历史行情（统一前复权），断点续传、瞬时网络失败按冷却自动重试，批次内逐代码实时进度展示。

## 启动方式

先进入代码仓库：

```bash
cd /Users/douzihao/StockManager/code
```

首次运行会自动检测 Python 3.11+、创建 `.venv`、执行 `pip install -e '.[dev]'`（下载 baostock/tzdata 等，约 1–2 分钟），然后启动服务并打开浏览器；后续启动会检查依赖，已安装且可导入时跳过安装。服务已在运行时重复点击只会打开浏览器（幂等，不会重复启动）。

### macOS

- **双击脚本（推荐，最简）**：在 `code` 目录中双击 `scripts/StockManager.command`，即可启动并自动打开浏览器；也可为该脚本创建 Finder 替身放到桌面。
  - 脚本按自身位置定位代码目录，移动整个项目无需修改路径；请保留原脚本在 `scripts/` 内。已有 `StockManager.app` 移动后需在新目录重新运行 `./scripts/make_app.sh`。
- **桌面 App（带图标）**：先运行 `python3 scripts/make_icon.py` 生成图标（若已生成可跳过），再运行 `./scripts/make_app.sh`，在代码仓库根生成 `StockManager.app`，双击图标即可启动。
- **命令行方式**：

  ```bash
  python3 scripts/launcher.py start    # 启动并打开浏览器
  python3 scripts/launcher.py status   # 查看运行状态
  python3 scripts/launcher.py restart  # 重启
  python3 scripts/launcher.py stop     # 停止
  ```

### Windows

- **双击启动（推荐，最傻瓜）**：把项目拷到 Windows 后，直接双击 `scripts\StockManager.bat`。首次会自动查找 Python 3.11+、创建 `.venv`、安装依赖、启动服务、打开浏览器，并**自动在桌面生成带图标的 StockManager 快捷方式**；之后双击桌面图标即可。
- **快捷方式补救**：若桌面图标缺失，双击 `scripts\setup_windows.bat` 重新生成（快捷方式指向 `StockManager.bat`）。
- **单文件 exe（可选，免装 Python）**：在 Windows 上双击 `scripts\build_windows_exe.bat` 打包，产物为 `dist\StockManager.exe`；把它复制到任意文件夹双击即可运行，数据存放在 exe 所在目录。打包脚本会自动安装并嵌入全部运行时依赖（含 backtrader 回测引擎），若检测到依赖缺失会先执行安装，无需手动补装。
- **云端构建 exe（推荐，本机全程免装任何东西）**：在 GitHub 仓库 Actions 页手动运行 `build-exe`（推送 `main` 或提交 PR 时也会自动触发），构建完成后在 `StockManager-windows-exe` 产物下载 `StockManager.exe`，复制到任意 Windows 机器双击即可运行。打包在 GitHub 的 Windows runner 上完成，产物已内嵌全部依赖（含 backtrader 回测引擎），无需在本机安装 Python 或任何依赖。
- **命令行方式**（在代码仓库根执行）：

  ```bat
  scripts\launcher.py start    & 启动并打开浏览器（首次自动装依赖）
  ```

  也可直接双击 `scripts\StockManager.bat` 走同一流程。

## 内置筛选规则

规则通过模板配置开关与参数，Web 工作台的规则目录由后端元数据自动生成（`GET /api/rules`）：

| rule_id | 名称 | 说明 |
| --- | --- | --- |
| `pe_positive` | PE 下限 | PE TTM 必须存在并严格大于下限；用于排除亏损或微利股票 |
| `non_st` | 排除 ST | 股票不得标记为 ST |
| `volume_price_5d` | 量价信号 | 相邻交易日同时满足量比和收盘涨幅 |
| `limit_up_breakout` | 炸板或假阴线 | 检查涨停炸板或假阴线信号 |
| `limit_up_3m` | 涨幅次数 | 统计窗口内涨幅事件次数 |
| `volatility_multiple` | 波动倍数 | 限制窗口最高价与最低价的倍数 |
| `annual_min_volume` | 年度最低交易量 | 目标日是否为自然日窗口最低交易量 |
| `annual_min_close_price` | 年度最低收盘价 | 目标日是否为自然日窗口最低收盘价 |
| `consecutive_up_days` | 连阳 | 最近N个交易日窗口内出现至少K个连续上涨交易日（K连阳） |
| `n_day_close_above` | N日收盘价下限 | 最近N个交易日每天的收盘价都严格高于设定值 |
| `volume_sum_extreme` | 连续量能极值 | 最近连续N天的成交量之和是所有连续M天成交量之和中的最低值或最高值 |
| `price_range_ratio` | N日高低点倍率 | 最近N个交易日内最高价相对最低价的倍数落在指定区间内 |

系统默认模板把基本面（PE、非 ST）设为全部满足、信号组（量价、炸板、年度最低量/最低价）任一满足、风险组（涨幅次数、波动）全部满足。

## 回测系统（P5C，自 1.16.0 起为独立整页视图）

历史筛选 + Backtrader 一体化回测，独立于「筛选工作台」的第三个整页视图（顶栏「回测系统 →」进入，「→ 筛选工作台 / 数据同步」返回）。策略目录由 `GET /api/research/policies` 自动生成：

| 类别 | policy_id | 说明 |
| --- | --- | --- |
| 入场 entry | `eligibility_enter_v1` | 资格名单出现即允许进入（服从执行约束） |
| 入场 entry | `pullback_entry_v1` | 筛选通过后不立即买入，等价格自近 N 日高点回落 drawdown_ratio 后再买入（回调入场） |
| 入场 entry | `sma_below_v1` | 收盘价低于 N 日均线时买入（均线买入，均值回归） |
| 退出 exit | `eligibility_exit_v1` | 不再合格即退出 |
| 退出 exit | `sma_timing_v1` | 收盘价跌破 N 日均线时退出 |
| 退出 exit | `fixed_holding_v1` | 持有 N 个交易日后退出 |
| 退出 exit | `take_profit_partial_v1` | （旧档）上涨到 take_profit_ratio 后卖出一定比例止盈；1.16.0 起推荐使用下方「独立止盈档」，本项仅为旧策略兼容保留 |
| 退出 exit | `sma_above_v1` | 收盘价高于 N 日均线时卖出（均线卖出，均值回归） |
| 再平衡 rebalance | `daily_v1` | 每个交易日收盘后重算目标组合 |
| 分配 allocation | `equal_weight_v1` | 等权分配：每只目标股资金 = 净资产 / 目标持仓数 |
| 分配 allocation | `add_position_on_dip_v1` | 持有中回调 add_drawdown_ratio 且有现金则按 add_fraction 补仓（最多 max_additions 次） |
| 排名 ranking | `turnover_20d_desc_v1` | 按近 20 日平均换手率降序取候选 |
| 执行 execution | `ashare_execution_v1` | A 股执行模型：次日开盘成交、T+1、整手、停牌/涨跌停（费用与整手已移至运行级基础数据，不再是政策参数） |

页面分三栏：

- **左栏 · 回测基础数据（运行环境）**：资格模式（「套用模板资格」/「忽略资格纯政策」，忽略资格必须至少填 1 个代码）、股票代码（多只逗号分隔；填 1 只即进入单股模式，此时排名/分配自动灰化不参与）；回测窗口支持近 1/3/5/8 年预设或自定义起止日期（精度到日，终点须 ≤ 本地最新已完成交易日）；初始资金、最大持仓数（唯一入口，覆盖分配政策参数）、Worker 并发数；费用组（佣金费率/印花税率/过户费率/最低佣金）与整手股数属「本次运行设置」，不进策略模板，可一键恢复默认。运行可取消（独立按钮）。
- **中栏 · 策略模版**：上方选择筛选模板（资格池，规则编辑仍在「筛选工作台」完成）；下方为命名策略模板编辑器——**入场组与退出组各支持 1~5 条政策并列（允许同名不同参数）**，组间关系可切换「任一满足 (OR) / 全部满足 (AND)」，每张政策卡下方显示所选政策的机制中文说明；**独立止盈档**（最多 5 档，低档优先，与退出组互不干扰：同日有全额退出信号时不减仓；触发涨幅与减仓比例统一按**小数**填写，如 `0.02`=2%、`0.1`=10%，不做任何百分制换算）；其它四类（调仓/分配/排名/执行）各单选一种。策略可校验、命名保存/另存为/删除（revision 乐观锁，冲突提示重新载入；内置默认策略只读），持久化于本地 `user_root/strategies/*.json`，与筛选模板机制一致。
- **右栏 · 回测结果与历史**：运行结束展示指标卡（初始/期末资金、总/年化收益、最大回撤、夏普、交易次数、累计费用）、逐点净值曲线与分页成交明细；历史运行列表可回看任意一次运行（含当时快照：资格模式、代码集、窗口、费用与策略引用）。点击任一行成交，弹出该股在回测窗口内的日 K 复盘浮层：买卖点以时间戳标注在对应 K 线上（买▲在上、卖▼在下，附价格×股数），支持缩放/平移/复位。
