## 何时登记（一条 Issue 只记一个指标/缺口）

- 目标/约束指标不存在：如组合级 alpha、CVaR、逐股 beta 之外的组合 beta、某行业/主题数据、新筛选规则或新字段；
- 口径与现有计算不匹配且无法在契约内冻结（如需要新的基准/利率期限/复权语义）；
- 其它阻塞技能运行的能力缺口（数据覆盖、交易日历、执行模型）。

**禁止重复建档**：登记前先在本目录检索是否已有同指标 Issue；存在则在原条目补充提出日期/场景/链接，不新建副本。

## 状态流转

- `open`：缺口存在，等待产品/数据实现或口径决策。
- `closed`：已实现或已确认不采纳；关闭时在备注注明验证证据（实现记录、测试、版本、运行链接或决策出处）。

- 技能与使用说明在输入端发现问题时引用：`project_doc/Issue/<文件名>`。
- 研究报告 / 运行报告在"限制与待决项"引用对应 Issue，说明对本次结果的影响。
