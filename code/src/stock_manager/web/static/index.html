模型公式 · 日 α 与年化 α

理论 CAPM 与实际回归

E(Rᵢ) = R𝒇 + βᵢ [E(Rₘ) − R𝒇]

理论描述均衡下预期收益与市场风险的关系；这里用历史样本估计含截距的回归：

yₜ = α + β xₜ + εₜ

xₜ = Rₘ,ₜ − R𝒇,ₜ，yₜ = Rᵢ,ₜ − R𝒇,ₜ

股票和指数均用简单收益率 Rₜ = Pₜ / Pₜ₋₁ − 1。股票采用前复权；指数保留其价格/全收益版本。

日频 α：窗口内的回归截距

β = Σ[(xₜ − x̄)(yₜ − ȳ)] / Σ(xₜ − x̄)²

α日 = ȳ − β x̄

每日模型调整后的收益差为 yₜ − βxₜ = α日 + εₜ，其样本均值是日 α。每个窗口估计一个日频 α，并非逐日另算一条 α 序列。

α年化 = α日 × 年化因子（默认 252）

例如日 α 为 0.02%，默认线性年化为 5.04%；不是复利，也不代表未来一年实际收益。

历史利率与有效样本

R𝒇,ₜ = Σ[各段年利率 × 各段自然日数 / 365]

央行人民币整存整取存款基准利率是研究代理，并非可随时按该利率借贷的无风险投资。使用 [前收盘日, 当前收盘日)，跨调息按生效日切段，周末/节假日计入，闰年分母仍为 365。

窗口为 30 / 120 / 250 / 500 自然日，每窗至少 15 条有效收益；股票前复权历史至少跨 180 自然日。利率的 365 分母与 α 的 252 年化因子不同。

如何理解 α、β 和 R² · CAPM 的假设与局限

用来比较历史表现，不替代投资判断

α 较小或接近 0：样本中相对所选基准、扣除市场风险解释部分后的额外收益有限。α < 0：样本中的模型调整后表现为负；这只说明历史超额表现不支持明显优势，不等同于未来“没有机会”。

α > 0 也不保证未来获利。本页未计算标准误、p 值或置信区间，不能仅凭正负或大小判断统计显著性；短窗口、异常值和基准选择都可能明显影响估计。

β 表示收益对市场超额收益的历史敏感度，不是总风险；R² 是所选市场因子对样本收益波动的解释比例，不是收益预测准确率。R² = 1 − Σ εₜ² / Σ(yₜ − ȳ)²。

模型假设与本系统的近似

经典 CAPM 假设投资者在共同的单期框架中进行均值—方差优化、具有同质预期；市场无税费及交易摩擦，资产可分割/交易，可按同一无风险利率借贷。

理论市场组合包含全部风险资产。本系统用选定指数作为代理：行业指数并不是全市场组合，得到的是相对该行业基准的单因子 α；价格指数和全收益指数的分红口径不同，切换后结果不可脱离口径直接比较。

样本回归额外近似窗口内 β 稳定、关系线性。现实中的交易限制、利率期限、行业/风格因素和数据缺口可能让这些假设不成立。结果仅供研究参考，不构成投资建议。

理论与局限参考：Sharpe（1964）；Fama 与 French（2004）。
